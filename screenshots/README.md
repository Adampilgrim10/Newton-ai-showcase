# Screenshot Guide

This folder is for carefully selected Newton.ai product screenshots.

## Recommended screenshots

Use a small set of clean screenshots showing:

1. Solver input and worked solution
2. Explanation or similar-question workflow
3. Automated marking feedback
4. Generated assessment
5. Mock-paper/results experience

## Before adding any screenshot

Check the full image for:

- bearer/access tokens
- API keys
- cookies
- email addresses
- private account names
- real student information
- database IDs
- DevTools request headers
- environment variables

Crop or retake the screenshot if any of those are visible.

## Suggested filenames

```text
solver.png
marking.png
assessment.png
mock-paper.png
results.png
```
